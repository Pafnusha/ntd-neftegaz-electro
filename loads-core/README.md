# loads-core — цифровая модель электрической сети (MVP)

Расширяет модуль нагрузок РТМ (`loads-app.js`) объектами: источники (GRID / SOURCE_DG / UPS), секции, АВР, панели, автоматы, кабели, проверка проекта.

## Тесты

```bash
cd loads-core && npm test
# или: node tests/run-tests.js
```

## NTD (только известные)

- РТМ 36.18.32.4-92 — Кр, nэ, Ки
- ПУЭ гл. 1.2 (категории), гл. 1.3 (нагрев проводников) — без выдуманных номеров таблиц
- СП 256.1325800.2016 — размещение (параметрически)
- ГОСТ 2.702 / 2.701 / 2.710 / 2.755 — оформление схем

ΔU% и Iдоп — параметрические каталоги; полный расчёт КЗ — stub (Iкз задаётся).

## Режим AUTO/MANUAL

Поля QF и кабеля: `{ value, source, mode: 'auto'|'manual' }`. Пересчёт не затирает `manual`.
