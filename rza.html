Расчёт уставок РЗА 6–35 кВ

АЛТЕЙ / ЛЮТИК · интерактивный расчёт · PDF-протокол

Инструкция пользователя

1. Выберите модель терминала. 2. Укажите паспортные токи ТТ и расчётные токи в первичных амперах. 3. Укажите коэффициент самозапуска, полученный из анализа нагрузки, и выдержку времени, выбранную по карте селективности. 4. Нажмите «Рассчитать». 5. Проверьте условия и сохраните протокол через «PDF / Печать» → «Сохранить как PDF».

Модуль 1: МТЗ по условию отстройки от максимального рабочего тока, формула (3.27), стр. 42 методики; приведение к вторичным величинам — (2.3), (2.18), стр. 10, 12. Прочие условия согласования (3.29) и проверки должны выполняться отдельно.

Это расчётный помощник, а не автоматическое назначение эксплуатационных уставок. Нельзя вводить результаты в терминал без проверки схемы, КЗ, селективности, чувствительности, диапазонов уставок и актуального РЭ.

Результаты

Введите исходные данные и нажмите «Рассчитать».

Методические ограничения

Расчёт по (3.27) является только одним из условий выбора МТЗ. Для окончательного выбора требуются согласование со смежными защитами, анализ послеаварийных режимов, проверка чувствительности по применимым требованиям, проверка ТТ и выбор времени по селективности. Значение kсзп для двигателей выше 1 кВ следует определять индивидуальным расчётом. Проверка Kч в этом модуле — информационная, без автоматического вывода о соответствии норме.
