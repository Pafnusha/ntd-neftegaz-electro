Как пользоваться Free Claude Code в этом проекте

Claude Code — агент в терминале: читает и правит файлы папки, запускает тесты и git. Free Claude Code (FCC) — бесплатный переходник, который направляет запросы агента в бесплатные модели (NVIDIA NIM, Groq, Gemini, OpenRouter…) вместо платного API Anthropic. Установка один раз на компьютер — дальше агент работает во всех проектах.

1. Установка (PowerShell, один раз)

& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))

На вопрос «Install Claude Code?» — Y. Если загрузчик Claude Code выдал 403 (региональная блокировка claude.ai):

npm config set prefix $HOME\npm-global
npm install -g @anthropic-ai/claude-code
# затем повторить команду установки FCC выше

Linux/macOS вместо PowerShell: curl -fsSL https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh | sh

2. Бесплатная модель

  1. Заведите ключ на одном из сайтов: build.nvidia.com (рекомендуется), console.groq.com, aistudio.google.com, openrouter.ai.
  2. Запустите «Free Claude Code» (Пуск / трей) → откроется Admin UI.
  3. Providers → вставьте ключ → выберите MODEL из списка → Apply.
  4. В Model Config можно включить Fallback Models — автоматический переход на запасную модель при ошибке.

3. Подключение к этому проекту

git clone https://github.com/Pafnusha/ntd-neftegaz-electro.git
cd ntd-neftegaz-electro
gh auth login        # один раз: доступ git к GitHub
fcc-claude           # запуск агента в папке проекта

Первая фраза агенту: «прочитай CLAUDE.md и перескажи правила проекта». Там описаны: структура модулей, обязательная пересборка чанков *.gz.b64 после правок loads-draw.js, поднятие версий ?v=, тесты loads-core/tests, контроль наложений на листах, запрет артефактов в коммитах. Права агента ограничены файлом .claude/settings.json: можно читать/править/тестировать, коммит и push — только после явного подтверждения.

4. Как ставить задачи (формула: что + где + как проверить)

ПлохоХорошо
«исправь таблицу»«В nagruzki2.js в Таблице 2 добавь колонку Sр(kVA) по секциям; после правок запусти python tests/n2_test.py и покажи, что наложения текста на листе = 0»
«сделай схему красивой»«Проверь однолистную схему loads-draw.js по ГОСТ 2.304: все надписи на бумаге А1 должны быть ≥2,5 мм; подними размеры шрифтов, если меньше; пересобери чанки ; тесты не роняй»
«найди ошибку»«Ведомость РТМ и QF-автомат не сходятся при N=4/Nрез=2: воспроизведи тестом, найди место в loads-draw.js, почини, коммит не делай»

Команды сессии: /model — сменить модель, /status — состояние, Esc — прервать, два Ctrl+C — выход. Агент отвечает и пишет код по-русски — просите как коллегу.

5. Безопасность и дисциплина

  • Коммит/пуш — только по вашей команде; перед коммитом читайте git diff.
  • Испортили правками — git checkout -- . (откат всей рабочей папки).
  • Токены (GitHub PAT, ключи моделей) — не светить в чатах и не хранить в файлах проекта; PAT берите fine-grained, только на этот репозиторий.
  • Ключи FCC лежат локально в ~/.fcc — эта папка вне git.
