КАБЕЛЬНЫЙ КАЛЬКУЛЯТОР 0,4 / 6–35 кВ — NED-Plagum, проектная методика 3300-E, ПУЭ/ГОСТ/IEC
====================================================================================
Открытие:      файл index.html в любом браузере (работа офлайн).
Тесты ядра:    вкладка «Тесты» в браузере (контрольные проверки ядра).
Инструкция:    вкладка «Инструкция»; нормативные таблицы — вкладка «НТД и таблицы».

Возможности:
 • Схема блоками 10(6–35) кВ → 0,4 кВ: параметры на блоках, автоподбор сечения из базы NED-Plagum.
 • Режим расчёта: вся цепочка / только 6–35 кВ / только 0,4 кВ.
 • Ручной override марки и сечения; проверка невозгораемости (нг / нг(А)-LS / ГОСТ 31565).
 • Сохранение проектов (localStorage) + импорт/экспорт JSON; редактируемый пример без имени заказчика.
 • Word-отчёт (.doc) с формулами и подставленными значениями, Excel/CSV, схема PNG.

 • 3300-E-000-EL-PHI-00009-00-D ред.03U (проектная методика): таблицы 1–2 токов IEC 60364-5-52 / 60502-2,
   kAT (табл.3), kGA/kHA (§7.7), формула (1) k=√((K−T)/(K−t)); ΔU §7.9; КЗ §7.10 (адиабатное, K=143 XLPE Cu).
 • Каталоги NED-Plagum 2025 (ООО «НЕД-Пермь»): SN 6–35 кВ и 0,66/1 кВ (ЭПР), исполнения нг(А)-LS/HF.
 • ПУЭ изд.6/7: 1.3.3, 1.3.10, 1.3.23–1.3.26, 1.3.29, 3.1.10–3.1.12, 7.3.97.
 • ГОСТ 31565-2012, ГОСТ 32144-2013, ГОСТ 31996-2012, ГОСТ 22483, IEC 60364-5-52, IEC 60502-1/-2.
 • Методические рекомендации по потерям в сетях 10(6)–0,4 кВ (Роскоммунэнерго, 2001).
