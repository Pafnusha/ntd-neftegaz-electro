1. Откройте https://github.com/Pafnusha/ntd-neftegaz-electro/settings/pages
2. Source: **GitHub Actions** (или Deploy from a branch → `main` / `/ (root)`).
3. Если в Actions ран ждёт Review: нажмите **Review deployments** → Approve.
4. Обновите страницу через 1–2 минуты.
